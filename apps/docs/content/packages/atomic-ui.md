# `@repo/atomic-ui` ⚛️

Shared component library adhering to Atomic Design principles (Atoms, Molecules, Organisms).

## Structure

- **Atoms**: Basic UI primitives (Button, Input, Text, Badge).
- **Molecules**: Form groups, search bars, card headers.
- **Organisms**: Navigation bars, sidebars, modal dialogs.

## Installation / Import

```typescript
import { Button } from "@repo/atomic-ui";
```
