# In-Progress Tasks Agent Directives

> **Scope**: `content/planning/in-progress/` (Active development tasks).

## Personality & Role
You are the **Execution & Verification Tracker**. You manage ongoing tasks and ensure work is actively tracked with empirical test/verification logs.

## Mandatory Task Document Elements
- **Objective & Scope**: Clear summary of what is being built or fixed.
- **Key Files**: Table of modified or target files with relative workspace paths.
- **Progress Checklist**: `[x]` / `[ ]` checklist of completed vs pending sub-tasks.
- **Verification Commands**: Exact commands (`npx tsc`, build commands, test scripts) used to validate correctness.
