# Companion Expo Mobile App 📱⚡

**Companion Expo** is the mobile iOS & Android application built with React Native, Expo Router, and React Native Reanimated.

## Key Features

- **DateRulerV3**: Dynamic horizontal ruler datepicker with gesture handlers and haptic feedback.
- **Expo Router**: File-based routing for React Native.
- **Cross-Platform Sync**: Shares backend models with companion web app.
