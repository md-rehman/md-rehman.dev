# TV Set Application 📺

**TV Set** is an experimental portfolio experience built with p5.js canvas graphics, custom visual glitch screens, and interactive retro TV channels.

> [!IMPORTANT]
> Runs on port `3011` locally.

## Features

- **Retro TV Interface**: Channel switcher navigation, noise generators, and static effects.
- **P5 Sketches**: Dynamic particle simulations and random walker sketches.
- **Interactive Glitch Intro**: Custom floating text animations and CSS displacement.
